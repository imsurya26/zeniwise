## 🐛 Troubleshooting

### App won't start?
```bash
rm -rf node_modules .next
npm install
npm run dev
```

### Port 3000 in use?
```bash
npm run dev -- -p 3001
```

### Build errors?
```bash
npm run build
# Check error messages
# Usually missing dependencies
```

### Can't see changes?
- Hard refresh: Ctrl+Shift+R (Windows)
- Or: Cmd+Shift+R (Mac)
- Clear browser cache
- Restart dev server
